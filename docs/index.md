# Anno 117 save tools

Documentation for `anno117.py`, a dependency-free Python tool that reads
**Anno 117: Pax Romana** save games and game data.

- [Save game format](save-format.md): RDA v2.2 container, FileDB v2, sessions, ships, owners.
- [Game data and GUID names](game-data.md): getting official names out of the game's `.rda` archives.
- [GUID reference](guids.md): a table of known GUIDs.

> Unofficial fan project, not affiliated with or endorsed by Ubisoft.
