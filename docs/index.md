# Anno 117 save tools

Documentation for `anno117.py`, a dependency-free Python tool that reads
**Anno 117: Pax Romana** save games and game data (only the `map` command needs Pillow).

- [Save game format](save-format.md): RDA v2.2 container, FileDB v2, sessions, ships, owners, islands, warehouses and their 20-minute history, game time, city names.
- [Game data and GUID names](game-data.md): getting official names out of the game's `.rda` archives, and the map tiles used by `map`.
- [The report page](report.md): the HTML page with alarms, island view and forces, made to stay open next to the game.
- [GUID reference](guids.md): every land unit, ship, ship module and defensive tower in the game, with internal and English names.

> Unofficial fan project, not affiliated with or endorsed by Ubisoft.
